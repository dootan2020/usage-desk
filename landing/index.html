GOOD TO KNOW

A few answers.

Still curious? Ask on GitHub ↗

Does this switch my LLM accounts?

No. Usage desk monitors accounts reported by supported official clients. It does not rotate accounts, buy credits or enable paid extra usage.

How do I sign in?

Install the official client, open Connections in Usage desk, set up the bridge and complete the provider’s own login. Then check fresh usage. Bridge setup alone does not mean usage is live.

Why does a provider show “Last known”?

The last real observation is retained when a read fails or becomes stale. Check Connections and reconnect in the official client when needed. Missing data is never shown as zero.

Can I use it on macOS or Linux?

This release is a Windows x64 taskbar app. It does not include a macOS or Linux desktop installer.

Is the installer signed?

Not yet. This is an unsigned release candidate. Publisher signing and clean Windows acceptance are pending. Check the release checksum; a checksum verifies file integrity, not publisher identity. Do not disable Windows security.

What does the public repository contain?

Installers, checksums, release notes and user guides. It is a distribution repository; the application source is not published there.

What stays after uninstalling?

Owned client integrations are restored. Private telemetry, client/browser profiles, backups and preferences are retained so your personal data is not silently removed.
